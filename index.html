Connect your local AI

HustleKit works in demo mode right away. To generate with an open-weight model on your own computer:

  1. Install Ollama.
  2. In Terminal, run ollama run llama3.2.
  3. Serve this folder locally (for example, VS Code Live Server), then click Connect local model below.

Local connection may require allowing your local web origin in Ollama's CORS settings. The app never falls back to a hosted AI API.
